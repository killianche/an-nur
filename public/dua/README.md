# Тексты дуа — как их прислать

Файл `dua.json` сейчас пустой намеренно. Дуа — сакральный текст: он не
придумывается и не берётся «из памяти модели», а переносится посимвольно
из источника, который дал владелец (см. `CLAUDE.md`).

Раздел, экраны, «Мой список» и формат готовы и работают. Осталось
наполнить.

## Как удобнее прислать

Годится любой из вариантов — разбор на мне:

- обычным сообщением: заголовок, арабский, транскрипция, перевод, источник;
- фотографией страницы книги;
- таблицей или текстовым файлом.

Главное — чтобы было видно, **откуда** текст: название книги, сборник
хадисов с номером или ссылка `сура:аят`. Без источника дуа в приложение
не попадёт.

## Что показывается на экране

Обязательно:

- **арабский** — крупно, шрифтом мусхафа;
- **перевод** на русский.

Необязательно, но если пришлёшь — покажется:

- **транскрипция** русскими буквами;
- **источник** — строчкой под текстом;
- **сколько раз читают**, если это оговорено.

## Формат файла

```json
{
  "version": 1,
  "categories": [
    { "id": "morning", "title_ru": "Утренние", "subtitle_ru": "После фаджра" },
    { "id": "road",    "title_ru": "В дорогу" }
  ],
  "entries": [
    {
      "id": "dua-001",
      "category": "road",
      "title_ru": "При выходе из дома",
      "arabic": "…",
      "translit_ru": "…",
      "russian": "…",
      "refs": ["Абу Дауд 5095"],
      "repeat": 1
    }
  ]
}
```

Поля `id` и `category` — служебные, их проставлю я. От тебя нужны
`title_ru`, `arabic`, `russian` и источник; остальное по желанию.

## Правило переноса

Текст копируется **один в один**: ни один символ не меняется, не
добавляется и не убирается — ни огласовка, ни пробел, ни запятая. Если я
замечу в присланном что-то похожее на опечатку, я не стану её молча
править: перенесу как есть и отдельно спрошу.
