# Общий контекст для всех агентов проекта an-Nur

Этот файл не является агентом. Его содержимое дублируется в каждое определение
агента, потому что субагент **не видит** диалог основной сессии и не читает
`CLAUDE.md` автоматически. При правке проектного контекста — обновлять здесь и
переносить в определения агентов.

## Проект

**an-Nur** (репозиторий QuranRu) — русскоязычное приложение для чтения Корана:
арабский текст, перевод Кулиева, аудио пяти чтецов с пословной подсветкой,
полноэкранный мусхаф, цветной таджвид, дуа, азкары, время намаза, кибла.

Стек: React 18 + TypeScript 5.6 + Vite 6 + Tailwind 4, Capacitor 8 (iOS + Android).
Роутера нет — самодельная навигация поверх History API в `src/App.tsx`.
React Context не используется; состояние — локальный `useState` + кастомные хуки
+ `localStorage` (веб-настройки) + Capacitor Preferences (нативная персистентность).
Бэкенда и БД нет. Все данные Корана — статические модули в `src/content/`.

## Сакральный текст — приоритет выше всего

Любой арабский текст Корана и азкаров, любой перевод, любая транскрипция
переносятся **посимвольно (verbatim)**. Запрещено: нормализовать пробелы и
диакритику, менять пунктуацию и кавычки, убирать невидимые символы, «исправлять»
опечатки, сокращать, дополнять. Источник — только программный
(`mcp.quran.ai`, quran.com), **никогда не по памяти модели**. Русский перевод
на весь проект один: Эльмир Кулиев, `edition_id: ru-kuliev`.

При малейшем сомнении в источнике — **не добавлять**, вернуть вопрос владельцу.
Гард: `npm run check:sacred` (посимвольная сверка со снапшотами).

Где аят цитируется, на экране обязаны быть одновременно арабский + перевод +
ссылка `сура:аят`. Только перевод — нарушение.

## Граница проекта

Единственный рабочий проект — QuranRu / an-Nur. Другие репозитории на машине
(QuranIng, старые копии Quran reader, QuranByMadinah) — **неприкосновенны**:
не читать, не менять, не использовать как источник без прямого запроса владельца.

## Грабли, которые уже стоили времени

- Правка данных мусхафа заканчивается не сборкой, а `npx cap sync` и проверкой
  на устройстве — иначе в нативке остаются старые шрифты.
- `font-family` шрифта мусхафа обязано нести номер страницы: один PUA-код в
  разных шрифтах — разные слова.
- Кубики вместо аята недопустимы: пока шрифт не подтверждён — скелет, при сбое —
  плашка с повтором. Сбой сети ≠ успех.
- Готовность шрифта — по статусу `FontFace`, не через `document.fonts.check()`.
- `requestAnimationFrame` не тикает в скрытой вкладке — циклы ожидания на `setTimeout`.
- Цветной таджвид — официальный COLR v0/CPAL + `font-palette`; самодельная
  COLR v1-конверсия ломает цвета в WKWebView (тест это запрещает).
