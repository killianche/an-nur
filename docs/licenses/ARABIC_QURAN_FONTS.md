# Основание использования арабских коранических шрифтов

Статус: **подтверждено для использования в Коране и коранических приложениях**.
Дата проверки: 2026-08-13.

## Решение владельца

Все используемые арабские коранические шрифты являются материалами
государственного Комплекса короля Фахда и предоставляются безвозмездно для
использования при отображении и издании Корана. Это **не public domain** и не
утверждение об отсутствии правообладателя: основание использования — разрешение
правообладателя для Корана и коранических приложений. В an-Nur они применяются
по этому назначению — для коранического текста и страниц мусхафа.

## Официальные основания

- Платформа разработчиков Корана Комплекса короля Фахда:
  `https://qurancomplex.gov.sa/quran-dev/`
  описывает цифровой мусхаф и компьютерный шрифт как материалы для разработчиков
  и издателей, предназначенные для настольных, мобильных и браузерных приложений.
- Права использования цифрового мусхафа:
  `https://dm.qurancomplex.gov.sa/rights/`
  разрешают бесплатное использование указанной цифровой копии в личных,
  государственных, частных и общественных проектах, печати, медиа, веб-сайтах
  и компьютерных программах внутри и вне Саудовской Аравии.
- Официальный каталог шрифтов: `https://fonts.qurancomplex.gov.sa/`.
- Официальное приложение публикации мусхафа:
  `https://nashr.qurancomplex.gov.sa/en/`.

## Как применено в an-Nur

- QCF/QPC-файлы используются только для коранического рендера.
- Постраничные WOFF2-подмножества не меняют текст или рисунок глифов: они
  удаляют неиспользуемые глифы для быстрой загрузки. Тождество контуров и ширин
  проверяется генератором на всех 604 страницах; подробности —
  `MUSHAF_FONTS.md`.
- Атрибуция Комплекса короля Фахда и каллиграфа Усмана Таха сохраняется.
- При смене источника или назначения использования проверка прав выполняется
  заново.

Локальный `public/qcf4/LICENSE.md` относится к конкретной сторонней упаковке
данных и содержит осторожную оговорку о font files. Для релиза основанием
служат официальные разрешения государственного правообладателя выше и решение
владельца использовать шрифты строго для Корана. Файл стороннего источника не
удаляется и поставляется вместе с соответствующим набором.
