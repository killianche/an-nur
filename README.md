# QuranRu

Приложение для чтения Корана на русском: арабский текст, перевод Кулиева, аудио с
пословной подсветкой, азкары. Веб + нативные обёртки iOS и Android через Capacitor.

Упрощённая копия проекта [QuranIng](../QuranIng) — без ингушского языка, с тремя темами
и двумя чтецами. Полное сравнение и текущее состояние — в [STATUS.md](STATUS.md).

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер Vite |
| `npm run build` | Проверка типов + production-сборка в `dist/` |
| `npm run preview` | Локальный просмотр production-сборки |
| `npm run check:sacred` | Гард сакрального текста — посимвольная сверка со снапшотами |
| `npm run sync` | Сборка + `npx cap sync` (обновить нативные проекты) |

## Структура

```
src/
  App.tsx           навигация между экранами (History API, без роутера)
  screens/          экраны: список сур, чтение, азкары, закладки
  components/       рендеры арабского, настройки, плеер, фоновые слои
  hooks/            аудио, загрузка страниц мусхафа, темы
  lib/              настройки, темы, типографика, утилиты
  content/          тексты Корана, тайминги слов, глифы таджвида
public/
  qcf4/             мусхаф King Fahd Complex 1441 — 604 страницы + шрифты
  qcf1/             мусхаф Мадани 1405
  fonts/            604 постраничных шрифта цветного таджвида
  audio/            mp3 Аляфаси, суры 67–114
  azkar/            азкары: тексты + аудио
scripts/
  check-sacred-text.mjs   гард сакрального текста
  gen/                    генераторы контента (тайминги, тексты, шрифты)
```

## Правила работы

Перед началом работы прочитать [CLAUDE.md](CLAUDE.md) и [STATUS.md](STATUS.md).
Отдельно обратить внимание на раздел «Сакральные правила кораничного текста» —
любой арабский текст и перевод переносится посимвольно, без нормализации.
