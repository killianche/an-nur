# QuranRu

Приложение для чтения Корана на русском: арабский текст, перевод Кулиева, аудио с
пословной подсветкой, азкары. Веб + нативные обёртки iOS и Android через Capacitor.

Исторически проект был создан на базе QuranIng, но сейчас это самостоятельный
продукт. Полное текущее состояние — в [STATUS.md](STATUS.md).
Источники готовых расписаний намаза для Назрани описаны в
[PRAYER_TIMETABLES.md](PRAYER_TIMETABLES.md).
Подготовка аккаунта и публикации iOS — в
[APPLE_ACCOUNT_CHECKLIST.md](APPLE_ACCOUNT_CHECKLIST.md) и
[APP_STORE.md](APP_STORE.md).
Основание использования арабских государственных шрифтов — в
[docs/licenses/ARABIC_QURAN_FONTS.md](docs/licenses/ARABIC_QURAN_FONTS.md).

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер Vite |
| `npm run build` | Проверка типов + production-сборка в `dist/` |
| `npm run preview` | Локальный просмотр production-сборки |
| `npm run check:sacred` | Гард сакрального текста — посимвольная сверка со снапшотами |
| `npm run sync` | Сборка + `npx cap sync` (обновить нативные проекты) |
| `node scripts/gen/fetch-luhaidan-ayah-ranges.mjs` | Пересобрать локальные границы 6236 аятов Люхайдана |
| `node scripts/gen/fetch-qurancom-ayah-ranges.mjs` | Пересобрать границы аятов непрерывных записей остальных четырёх чтецов |

## Правила работы

Перед началом работы прочитать [CLAUDE.md](CLAUDE.md) и [STATUS.md](STATUS.md).
Отдельно обратить внимание на раздел «Сакральные правила кораничного текста» —
любой арабский текст и перевод переносится посимвольно, без нормализации.

Общий код an-Nur хранится в `src/` и `public/`, но Web, iOS и Android имеют
отдельные контуры выпуска. Перед задачей фиксируется целевая платформа:

- Web: `npm run check:sacred`, `npm run build`, затем только `dist/` в
  `62.113.106.30:/var/www/an-nur`;
- iOS/Android: `npm run sync` переносит одну проверенную сборку в нативные
  проекты; ручные правки сгенерированных `public/` запрещены;
- новая сборка iOS не появляется в App Store без отдельного архива и загрузки.

Нельзя автоматически публиковать изменения на остальные платформы, если
владелец выбрал только один контур релиза. В итоговом отчёте всегда указывать,
какие из Web/iOS/Android реально обновлены.
